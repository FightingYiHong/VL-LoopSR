NoiseRobust-SR v1 construction log

Purpose
  Fixed noisy symbolic-regression replicas for evaluating structural recovery
  under observation noise. The method sees noisy train/validation targets but
  is scored against clean test targets and known symbolic skeletons.

Construction
  1. Select 20 analytic formula specifications with ground-truth expressions.
  2. For each formula, sample variables uniformly from [-2, 2].
  3. Generate clean targets y_clean from the analytic expression.
  4. For train and validation only, add target-scale Gaussian noise:
       y_noisy = y_clean + Normal(0, alpha * std(y_clean)).
  5. Keep test targets clean for final structural recovery scoring.
  6. Repeat each formula/noise-level pair for 3 independent seeds.

Noise levels
  0,0.001,0.01,0.05,0.1

Dataset size
  formulas: 20
  noise levels per formula: 5
  seeds per formula/noise pair: 3
  total tasks: 300
  train rows per task: 512
  validation rows per task: 256
  clean test rows per task: 1024
  total rows across all task files: 537600

Files
  manifest.csv: one row per fixed task with paths and noise metadata.
  formulas.csv: one row per ground-truth formula.
  splits/<case_id>/train_noisy.csv: training split used by methods.
  splits/<case_id>/val_noisy.csv: validation split used by methods.
  splits/<case_id>/test_clean.csv: clean scoring split.
  splits/<case_id>/train_clean.csv and val_clean.csv: analysis-only clean labels.
  splits/<case_id>/meta.json: per-task metadata.

Scoring protocol
  Exact Recovery and Skeleton Recovery compare discovered expressions against
  the clean formula and clean test set. No method is given train_clean.csv or
  val_clean.csv during fitting.

Reproducibility
  generator: scripts/generate_noise_robustness_dataset.py
  base random_state: 42


NoiseRobust-SmallRange v1 selection
  This manifest keeps all 20 formulas from NoiseRobust-SR v1_20 and selects
  a smaller but nontrivial observation-noise range alpha in {0, 0.001, 0.01}.

Selection rule
  Keep every formula and every seed, but restrict noise_level to 0, 0.001,
  and 0.01. This preserves a clean anchor, a weak-noise condition, and a
  moderate 1% target-scale noise condition, while excluding the extreme 5% and
  10% stress levels where exact symbolic skeletons become less identifiable.

Rationale
  The goal is to evaluate structural recovery under realistic small-to-moderate
  target noise rather than under very high noise that can favor noise-fitting or
  simplified predictors. The full v1_20 manifest remains the robustness stress
  test and should be reported separately.

Small-range size
  formulas: 20
  noise levels: [0.0, 0.001, 0.01]
  seeds per formula/noise pair: 3
  total tasks: 180


Exact-recovery post refinement
  Motivation
    In the 100s V11 noise setting, many failures are not structural failures:
    the recovered expression uses the right active variables and a compact
    skeleton, but the fitted constants are slightly off, so the strict exact
    threshold is missed. This mainly hurts Exact Recovery relative to baselines
    that run longer numerical refinement internally.

  Procedure
    After V11 returns its final expression, run a deterministic coefficient-only
    post-processing step. The step does not use the ground-truth expression,
    train_clean.csv, val_clean.csv, or clean test labels for selection.

    Candidate expressions are generated from the returned expression by:
      1. keeping the original expression;
      2. snapping floating constants to small rationals with denominator <= 20;
      3. fitting an affine wrapper a*f(x)+b on noisy train targets;
      4. refitting additive term coefficients on noisy train targets;
      5. applying the same small-rational snapping to the refitted candidates.

    Candidates are selected by noisy validation MSE, with a 5% near-tie window
    favoring lower expression complexity. Clean test MSE is computed only after
    candidate selection for reporting Exact/Skeleton Recovery.

  Implementation
    scripts/run_v11_noise_robustness.py supports this as
    LLMSR_NOISE_POST_SKELETON_REFINE=1.

    For completed runs, scripts/offline_noise_post_refine.py reproduces the same
    coefficient-only refinement from saved V11 expressions and fixed train/val/test
    CSV files.
